# 스타리치 상담 노트

**상담 중 과거 A/S 사례를 비교하고, 상담원이 확인할 질문과 결정한 내용을 한 화면 흐름에서 기록할 수 있는 웹 도구입니다.**

2026년 10월 한양대 ERICA 기업 문제 해결 해커톤에서 에벤커머스코리아의 스타리치 상담 미션을 바탕으로 만든 팀 프로젝트입니다. 이 저장소는 시연용 가상 사례 8건으로 구성한 포트폴리오 버전입니다.

## 어떤 문제를 풀었나요?

문의가 들어오면 상담원은 증상을 듣고, 과거 사례를 찾고, 고객에게 추가로 물어본 뒤 처리 방향을 기록해야 합니다. 같은 증상도 사용 상황이나 과거 처리 결과가 다를 수 있어 한 사례만 보고 판단하기 어렵습니다. 사례를 나란히 보면서 확인할 내용을 정리할 수 있도록 상담 순서를 여섯 단계로 나눴습니다.

| 단계 | 할 수 있는 일 |
| --- | --- |
| 01 문의 접수 | 제품 모델과 고객이 말한 증상 입력 |
| 02 과거 데이터 검색 | 제품과 증상이 비슷한 사례 찾기 |
| 03 상담원 판단 가이드 | 사례 2~3건의 발생 상황·확인 내용·기술팀 기록·처리 결과 비교 |
| 04 실시간 상담 지원 | 제품별 확인사항과 추가 질문 확인 |
| 05 처리 결정 | 상담원이 처리 방향과 안내 내용을 직접 기록 |
| 06 데이터 축적 | 저장 확인, 기존 기록 조회 및 후속 결과 추가 |

## 직접 체험하기

1. 이 저장소에서 **Code → Download ZIP**을 누르고 압축을 풉니다.
2. 같은 폴더에 있는 `index.html`을 브라우저로 엽니다.
3. **예시 상담**으로 검색을 시작합니다. B7B의 변속·소음 사례 두 건을 비교해 보세요.
4. 추가 질문을 확인하고 처리 방향을 선택해 상담을 저장합니다.
5. **상담 기록**에서 저장한 내용을 다시 확인합니다.

별도 설치나 로그인이 필요 없습니다. 데모에 입력한 기록은 현재 브라우저에 저장되며, 기록 화면에서 JSON으로 내보내고 불러올 수 있습니다.

## 구현 메모

- **검색:** 제품 모델로 먼저 좁히고, 증상 키워드와 표현이 얼마나 겹치는지 점수를 매겨 순서를 정합니다.
- **비교:** 발생 상황, 고객 설명, 기술팀 기록, 처리 결과를 같은 행에서 비교합니다. 참고할 사례가 없어도 상담을 계속할 수 있습니다.
- **결정:** 처리 방향은 상담원이 선택합니다. 프로그램이 고장 원인이나 수리 여부를 확정하지 않습니다.
- **저장:** 브라우저의 `localStorage`를 사용합니다. 다른 기기와 공유되지 않으므로 실제 고객 정보는 데모에 입력하지 마세요.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 데모 진입점 |
| `styles.css` | 화면 구성과 반응형 스타일 |
| `demo-data.js` | 시연용으로 작성한 가상 사례 |
| `app.js` | React·TypeScript로 개발한 최종 데모의 JavaScript 번들 |

이 저장소에는 기업이 제공한 사례 원본, 운영 상담 기록, 직원 공유 서버 설정이 들어 있지 않습니다. 가상 사례의 처리 결과는 제품의 공식 안내나 실제 고장 빈도를 뜻하지 않습니다.
